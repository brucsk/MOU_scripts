Scripts to fit data of schizophrenic versus control groups, characterized by the zero-lag and one-lag connectivity matrices (FC0, FC1), to a Multivariate Ornstein Uhlenbeck (MOU) process using gradient descent. From the matrices that describe the MOU, that is, $J$ and $\Sigma$, the Entropy Production Rate ($\Phi$) is extracted and then compared across groups.
\\
Tested with Python 3.10.12
